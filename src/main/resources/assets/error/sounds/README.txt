Маппинг GUI-звуков (как в Harmony):

- Открытие GUI → dropdownen
- Закрытие GUI → dropdowndis
- Категории → switchcategory
- Вкл/выкл модуля → moduleopen / moduleclose
- Раскрытие настроек модуля → openmodescreen / closemodescreen
- Тумблер (boolean) → closeselectsettings / openselectsettings
- Чекбокс (multi) → guienablecheckbox / guidisablecheckbox
- Mode → guichangemode
- Слайдер → slider
- Цвет open/close → guicoloropen / guicolorclose
- Бинд модуля → binding / bind / unbind
- Бинд настройки → guibinding / guibindreset
- Поиск → searchfield / searchtyping
- Клик (кнопки/темы) → click

Звуки модулей по хоткею (настройка «Тип»): slideenable/slidedisable и др.
