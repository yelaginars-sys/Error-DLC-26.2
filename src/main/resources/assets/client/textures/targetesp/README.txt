# TargetESP Textures

## Required Textures:

1. **chain.png** - Chain texture for the "Цепи" (Chains) mode
   - This should be a seamless chain link texture
   - Recommended size: 64x64 or 128x128 pixels
   - Should tile horizontally

## Note:
You need to add the chain.png texture file to this directory for the Chains effect to render properly.
